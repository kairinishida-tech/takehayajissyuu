# だっしゅつゲーム（小学生向け ブラウザ脱出ゲーム）

小学生がiPadのブラウザ（Safari）で遊べる、なぞときアプリのプロトタイプです。
ビルド不要（HTML + CSS + Vanilla JavaScript）で、`index.html` を開くだけで動きます。

- タイトル画面 → 複数のステージ（なぞとき）を順番にクリア → 最終演出で写真を表示
- ステージの中身は [`stages.js`](./stages.js) にまとまっており、ここを書き換えるだけで
  問題の追加・差し替えができます（ロジック側の `main.js` は変更不要）
- 現在の5ステージは、詰まらずテンポよく遊べるよう **通しで10分以内に確実に終わる**
  短めのボリュームに調整してあります（各ステージの目安は後述の「5. 現在のステージについて」参照）

---

## 1. ステージを追加・変更する方法

すべてのステージは [`stages.js`](./stages.js) の `STAGES` 配列にあります。
配列の要素を増やす／書き換えるだけで、ステージ数や内容を自由に変えられます。

### 共通で必要な項目

```js
{
  id: "stage-04",       // 他と重複しないID
  title: "だい4もん",     // ステージのタイトル
  type: "quiz",          // 出題形式（下記参照）
  prompt: "問題文をここに書く",
  image: null,            // ステージ用の画像パス（任意。使わないなら null）
  hint: "ヒント文をここに書く",
}
```

### 対応している出題形式（`type`）

現在5種類の `type` に対応しています（`quiz`・`order` はさらに2つずつの書き方があります）。

#### `"quiz"`（選択肢から選ぶ。2つのモードがある）

**① シンプル版（既定）** - 1つタップしたら即座に正誤判定

```js
{
  id: "stage-04",
  title: "だい4もん",
  type: "quiz",
  prompt: "日本でいちばん高い山は？",
  image: null,
  choices: ["富士山", "エベレスト", "つくば山", "阿蘇山"],
  answerIndex: 0,   // choices配列の何番目が正解か（0始まり）
  hint: "静岡県と山梨県にまたがる山だよ。",
}
```

**② 複数選択版（`multiSelect: true`）** - 正解の数だけタップしてから「けってい」で判定

```js
{
  id: "stage-quiz-2",
  title: "だい2もん",
  type: "quiz",
  multiSelect: true,
  prompt: "体育のあいことばを3つえらんでね（じゅんばんは関係ないよ）。",
  image: null,
  choices: ["ファイト", "ナイス", "ドンマイ", "がんばれ", "オーケー", "よし"],
  correctAnswers: [0, 1, 2],   // choices配列のインデックスの配列。順序は問わない
  hint: "なかまを おうえん・はげます ときに つかう ことばだよ。",
}
```

選んだ選択肢の集合が `correctAnswers` と完全に一致すれば正解（選ぶ順番は自由）。
不正解のときは選んでいたボタンが揺れて「❌ おしい！もういちど えらんでみよう！」と
表示され、選択を保ったまま何度でも選び直せます。

#### `"code-input"`（キーボードで答えを入力する）

```js
{
  id: "stage-05",
  title: "だい5もん",
  type: "code-input",
  prompt: "1年で一番はじめの月は？ 数字で答えてね。",
  image: null,
  answer: "1",
  placeholder: "すうじで にゅうりょく",
  hint: "1月、2月、3月…の「1」だよ。",
}
```

入力判定は全角/半角・大文字/小文字・前後の空白を自動で吸収するので、
子どもが多少表記ゆれのある入力をしても正解と判定されやすくなっています。

#### `"order"`（並べ替え。2つの書き方がある）

**① シンプル版** - 表示されたピースを正しい順番でタップする

```js
{
  id: "stage-06",
  title: "だい6もん",
  type: "order",
  prompt: "小さい順にタップしよう。",
  image: null,
  items: ["5", "1", "3"],       // 表示される順番
  correctOrder: [1, 2, 0],       // items のインデックスで正解の順番を指定
  hint: "いちばん小さい数字から選んでね。",
}
```

上の例では `items[1]="1"` → `items[2]="3"` → `items[0]="5"` の順にタップすると正解、という意味です。

**② リッチ版** - `{label, detail, icon}` のカードを、持ち手（☰）を指でなぞって
スライドさせながら並べ替える

```js
{
  id: "stage-07",
  title: "だい7もん：手順をならべよう",
  type: "order",
  prompt: "作業の手順を正しい順番にならべよう。カードをタップすると詳しい説明が見られるよ。",
  image: null,
  // items は「正解の順番」で書けばOK（correctOrderは省略可）。
  // 画面には自動でシャッフルされた状態で表示され、持ち手(☰)をスライドさせて並べ替える。
  items: [
    { label: "① まずやること",   icon: "🎧", detail: "タップすると出る詳しい説明文" },
    { label: "② つぎにやること", icon: "✏️", detail: "……" },
    { label: "③ さいごにやること", icon: "🔊", detail: "……" },
  ],
  hint: "①から順番に考えてみよう。",
}
```

`items` の各要素が `{label, detail}` のオブジェクトかどうかで、main.js側が自動的に
シンプル版／リッチ版を判定します（`type`は同じ`"order"`のままでOK）。
`icon` は絵文字1つ（複数個並べてもOK）を指定すると、カードの左側に大きく表示されます。
見た目を賑やかにしたいときや絵で内容をイメージしやすくしたいときに便利です（省略可）。
並べ替えは、各カード左側の「☰」持ち手を指でなぞって上下にドラッグする方式です
（Pointer Eventsによる自前実装で、外部ライブラリは使っていません）。カードの
文字部分をタップすると `detail` の説明がポップアップします。
リッチ版では `correctOrder` を省略すると、`items`を書いた順番がそのまま正解になります。
不正解のときは「❌ ここが ちがうかも…」というヒントを出し、並べた状態のまま再挑戦できます。

#### `"blackjack"`（コンピュータと数字ブラックジャック対戦）

```js
{
  id: "stage-blackjack",
  title: "コンピュータとブラックジャック勝負！",
  type: "blackjack",
  prompt: "1〜10のすうじカードだけをつかったかんたんブラックジャック！",
  image: null,
  rules: {
    maxTotal: 21,        // これを超えたらバースト（省略時21）
    dealerStandsAt: 17,  // コンピュータがこの数値以上で引くのをやめる（省略時17）
    cardMin: 1,          // 引くカードの最小値（省略時1）
    cardMax: 10,         // 引くカードの最大値（省略時10）
  },
  hint: "17以上でステイするのが基本の作戦だよ。",
}
```

`choices` や `items` などは不要です。カードの配布・「ひく」「ステイ」・コンピュータの
自動プレイ・勝敗判定・結果表示（勝ちなら「つぎへ」、負け／引き分けなら「もういちど」で
やり直し）はすべて `main.js` の `renderBlackjack` が自動で行います。`rules` を書き換えると
バーストするラインやカードの数字の範囲を調整できます。

#### `"fishing"`（お題に合う英単語の魚だけをタップして釣り上げる）

```js
{
  id: "stage-fishing",
  title: "えいたんご つりゲーム",
  type: "fishing",
  prompt: "およいでくる えいたんごの さかなの中から、おだいに あう たんごだけを タップしよう。",
  image: null,
  themeLabel: "どうぶつの えいたんごを つろう！", // 画面上部に出すお題
  timeLimitSec: 50,       // 制限時間（秒）
  targetCatches: 10,      // この数だけ正解を釣ればクリア
  correctWords: ["cat", "dog", "bird", "fish", "lion", "panda", "rabbit", "elephant"],
  wrongWords: ["red", "blue", "one", "two", "apple", "banana", "chair", "book"],
  hint: "どうぶつの単語だけをタップしてつかまえよう。ちがう単語はタップせず見送ろう！",
}
```

`themeLabel` / `correctWords` / `wrongWords` を書き換えるだけで、テーマ（お題）ごと
まるごと差し替えられます。魚は正解65%程度の比率でランダムに出現し、同時に画面に出る
数は最大4匹（多すぎて混乱しないように制限）。正解の魚をタップすると釣り上げ成功、
不正解の魚をタップするか制限時間内に目標数へ届かなかった場合は「小指を魚に噛まれる」
演出のあと、釣り上げ数・タイマー・魚をすべてリセットしてこのステージ内でやり直しに
なります。目標数に到達すると（時間が残っていても）即座にクリア扱いになります。
`timeLimitSec` と `targetCatches` は同じ比率で調整してあります（魚の出現頻度・
正解の比率・泳ぐ速さといった「1匹あたりの難易度」自体は変えていません）。
どちらか一方だけを変えると難しさが大きく変わるので、目標数を増減するときは
目安として `timeLimitSec ÷ targetCatches ≈ 5秒` になるよう合わせて調整してください。

### 新しい出題形式（typeを増やす）を追加したい場合

1. `stages.js` に新しい `type` の名前をつけてステージを追加する
2. `main.js` の `RENDERERS` オブジェクトに `"新しいtype名": 描画関数` を1行追加する
3. 描画関数を1つ実装する（`renderQuiz` / `renderCodeInput` / `renderOrder` /
   `renderBlackjack` / `renderFishing` が実装例です）
   - 描画関数は `(stage, container, handleResult, advanceStage)` を受け取ります
   - 画面のUIを `container` に追加し、答えが決まったタイミングで
     `handleResult(true, options)`（正解）または `handleResult(false, options)`（不正解）
     を呼ぶだけでOKです（`options`は省略可。`{ wrongMessage: "..." }` のように渡すと
     共通フィードバック欄の文言を上書きできます）
   - 正解時の演出・次のステージへの遷移などは `main.js` 側が自動で行います
   - ブラックジャックのように「結果画面に自前のボタンを出して、押されたタイミングで
     次のステージに進みたい」場合は、共通フィードバックを経由せずに
     `advanceStage()` を直接呼んでもOKです

## 2. 最終画面の写真を差し替える方法

最終画面（クリア画面）で表示される写真は、以下のどちらかのファイルを置くだけで反映されます。

```
escape-game/assets/final-photo.jpg
escape-game/assets/final-photo.png
```

- 既存のファイルを、表示したい写真で **上書き** してください（ファイル名は変えないこと）
- `.jpg` と `.png` の両方がある場合は `.jpg` が優先して読み込まれます
- どちらのファイルも見つからない場合は、画面に
  「写真が見つかりません。assets/final-photo.jpg（または .png）に画像を置いてください」
  という開発者向けのメッセージが表示されます（アプリ自体はエラーになりません）

現在入っている画像はプレースホルダー（仮の色つき画像）です。本番用の写真に差し替えてください。

## 3. ローカルでの動かし方

### 方法A: ファイルを直接ダブルクリックして開く

`index.html` をダブルクリックしてブラウザで開くだけでも動作します。

### 方法B: 簡易サーバーで配信する（推奨）

```bash
npx serve .
```

または VS Code の **Live Server** 拡張機能で `index.html` を右クリックして
「Open with Live Server」を選んでも同様に動きます。

表示されたURL（例: `http://localhost:3000` や `http://127.0.0.1:5500`）に
パソコンのブラウザからアクセスして動作確認できます。

---

## 4. iPadで開く際の注意点

- iPadと配信元のパソコンを **同じWi-Fiネットワーク** に接続してください
- パソコン側で簡易サーバーを起動したら、パソコンのローカルIPアドレス
  （例: `192.168.1.10`）を調べて、iPadのSafariから
  `http://192.168.1.10:3000` のようにアクセスしてください
  - Macでのローカルアドレス確認例: `ipconfig getifaddr en0`
- 学校のネットワークなどにホスティングする場合は、`escape-game` フォルダ一式を
  そのまま静的ファイルとして配信すれば動作します（サーバー側の処理は不要です）
- 本アプリは通信を必要とせず、すべてクライアントサイドで完結するため、
  一度読み込めばオフラインでも動作します

## 5. 現在のステージについて

現在、`stages.js` には以下の5ステージが入っています。**全体を通して遊んでも
10分以内に確実に終わる、短めのボリュームに調整済みです**（目安は下記）。

1. 体育のあいことばクイズ（`type: "quiz"`、複数選択版） - 目安15〜30秒
2. ひらがなで答えを入力する問題（`type: "code-input"`） - 目安20〜30秒
3. コンピュータとの数字ブラックジャック対戦（`type: "blackjack"`） - 目安15〜60秒
4. 紙コップスピーカーの作り方を並べ替える問題（`type: "order"`、リッチ版、4工程）
   - 目安45〜90秒
5. 英単語つりゲーム（`type: "fishing"`、制限時間50秒×目標10匹） - 目安50〜100秒

合計しても平均3〜4分、うまくいかず何度かやり直しても6〜7分程度で収まる想定です。
2は動作確認用の仮ステージなので、本番の謎解き内容が決まり次第、
自由に差し替えてください。1・3・4・5はそのまま使う想定の本番ステージです
（1の合言葉・5のテーマ・単語も、それぞれの項目を書き換えれば自由に差し替えられます）。

**さらに短く／長くしたいとき**

- ステージ数を減らす・増やす（`stages.js` の配列を編集）
- ステージ4の `items` の数を増減する（工程を足し引きするだけでOK）
- ステージ5の `timeLimitSec`・`targetCatches` を調整する（同じ比率で増減すること）
- ステージ3の `rules.dealerStandsAt` を下げると、コンピュータの手番が短くなる
