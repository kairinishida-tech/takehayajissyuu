# だっしゅつゲーム（小学生向け ブラウザ脱出ゲーム）

小学生がiPadのブラウザ（Safari）で遊べる、なぞときアプリのプロトタイプです。
ビルド不要（HTML + CSS + Vanilla JavaScript）で、`index.html` を開くだけで動きます。

- タイトル画面 → 複数のステージ（なぞとき）を順番にクリア → 最終演出で写真を表示
- ステージの中身は [`stages.js`](./stages.js) にまとまっており、ここを書き換えるだけで
  問題の追加・差し替えができます（ロジック側の `main.js` は変更不要）

---

## 1. ステージを追加・変更する方法

すべてのステージは [`stages.js`](./stages.js) の `STAGES` 配列にあります。
配列の要素を増やす／書き換えるだけで、ステージ数や内容を自由に変えられます。

### 共通で必要な項目

```js
{
  id: "stage-04",       // 他と重複しないID
  title: "だい4もん",     // ステージのタイトル
  type: "quiz",          // 出題形式（下記参照）
  prompt: "問題文をここに書く",
  image: null,            // ステージ用の画像パス（任意。使わないなら null）
  hint: "ヒント文をここに書く",
}
```

### 対応している出題形式（`type`）

現在3種類のtypeに対応しています。

#### `"quiz"`（選択肢から1つ選ぶ）

```js
{
  id: "stage-04",
  title: "だい4もん",
  type: "quiz",
  prompt: "日本でいちばん高い山は？",
  image: null,
  choices: ["富士山", "エベレスト", "つくば山", "阿蘇山"],
  answerIndex: 0,   // choices配列の何番目が正解か（0始まり）
  hint: "静岡県と山梨県にまたがる山だよ。",
}
```

#### `"code-input"`（キーボードで答えを入力する）

```js
{
  id: "stage-05",
  title: "だい5もん",
  type: "code-input",
  prompt: "1年で一番はじめの月は？ 数字で答えてね。",
  image: null,
  answer: "1",
  placeholder: "すうじで にゅうりょく",
  hint: "1月、2月、3月…の「1」だよ。",
}
```

入力判定は全角/半角・大文字/小文字・前後の空白を自動で吸収するので、
子どもが多少表記ゆれのある入力をしても正解と判定されやすくなっています。

#### `"order"`（表示されたピースを正しい順番でタップする）

```js
{
  id: "stage-06",
  title: "だい6もん",
  type: "order",
  prompt: "小さい順にタップしよう。",
  image: null,
  items: ["5", "1", "3"],       // 表示される順番
  correctOrder: [1, 2, 0],       // items のインデックスで正解の順番を指定
  hint: "いちばん小さい数字から選んでね。",
}
```

上の例では `items[1]="1"` → `items[2]="3"` → `items[0]="5"` の順にタップすると正解、という意味です。

### 新しい出題形式（typeを増やす）を追加したい場合

1. `stages.js` に新しい `type` の名前をつけてステージを追加する
2. `main.js` の `RENDERERS` オブジェクトに `"新しいtype名": 描画関数` を1行追加する
3. 描画関数を1つ実装する（`renderQuiz` / `renderCodeInput` / `renderOrder` が実装例です）
   - 描画関数は `(stage, container, handleResult)` を受け取ります
   - 画面のUIを `container` に追加し、答えが決まったタイミングで
     `handleResult(true)`（正解）または `handleResult(false)`（不正解）を呼ぶだけでOKです
   - 正解時の演出・次のステージへの遷移などは `main.js` 側が自動で行います

## 2. 最終画面の写真を差し替える方法

最終画面（クリア画面）で表示される写真は、以下のどちらかのファイルを置くだけで反映されます。

```
escape-game/assets/final-photo.jpg
escape-game/assets/final-photo.png
```

- 既存のファイルを、表示したい写真で **上書き** してください（ファイル名は変えないこと）
- `.jpg` と `.png` の両方がある場合は `.jpg` が優先して読み込まれます
- どちらのファイルも見つからない場合は、画面に
  「写真が見つかりません。assets/final-photo.jpg（または .png）に画像を置いてください」
  という開発者向けのメッセージが表示されます（アプリ自体はエラーになりません）

現在入っている画像はプレースホルダー（仮の色つき画像）です。本番用の写真に差し替えてください。

## 3. ローカルでの動かし方

### 方法A: ファイルを直接ダブルクリックして開く

`index.html` をダブルクリックしてブラウザで開くだけでも動作します。

### 方法B: 簡易サーバーで配信する（推奨）

```bash
npx serve .
```

または VS Code の **Live Server** 拡張機能で `index.html` を右クリックして
「Open with Live Server」を選んでも同様に動きます。

表示されたURL（例: `http://localhost:3000` や `http://127.0.0.1:5500`）に
パソコンのブラウザからアクセスして動作確認できます。

---

## 4. iPadで開く際の注意点

- iPadと配信元のパソコンを **同じWi-Fiネットワーク** に接続してください
- パソコン側で簡易サーバーを起動したら、パソコンのローカルIPアドレス
  （例: `192.168.1.10`）を調べて、iPadのSafariから
  `http://192.168.1.10:3000` のようにアクセスしてください
  - Macでのローカルアドレス確認例: `ipconfig getifaddr en0`
- 学校のネットワークなどにホスティングする場合は、`escape-game` フォルダ一式を
  そのまま静的ファイルとして配信すれば動作します（サーバー側の処理は不要です）
- 本アプリは通信を必要とせず、すべてクライアントサイドで完結するため、
  一度読み込めばオフラインでも動作します

## 5. 現在の仮ステージについて

初期状態では、動作確認用の仮ステージが3つ入っています（`stages.js` 参照）。
本番の謎解き内容が決まり次第、このファイルの中身を差し替えてください。
仮ステージは以下の3つです。

1. くだものを当てるクイズ（`type: "quiz"`）
2. ひらがなで答えを入力する問題（`type: "code-input"`）
3. 数字を小さい順にタップする問題（`type: "order"`）
