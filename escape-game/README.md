# だっしゅつゲーム（小学生向け ブラウザ脱出ゲーム）

小学生がiPadのブラウザ（Safari）で遊べる、なぞときアプリのプロトタイプです。
ビルド不要（HTML + CSS + Vanilla JavaScript）で、`index.html` を開くだけで動きます。

- タイトル画面 → 複数のステージ（なぞとき）を順番にクリア → 最終演出で写真を表示
- ステージの中身は [`stages.js`](./stages.js) にまとまっており、ここを書き換えるだけで
  問題の追加・差し替えができます（ロジック側の `main.js` は変更不要）

---

## 1. ステージを追加・変更する方法

すべてのステージは [`stages.js`](./stages.js) の `STAGES` 配列にあります。
配列の要素を増やす／書き換えるだけで、ステージ数や内容を自由に変えられます。

### 共通で必要な項目

```js
{
  id: "stage-04",       // 他と重複しないID
  title: "だい4もん",     // ステージのタイトル
  type: "quiz",          // 出題形式（下記参照）
  prompt: "問題文をここに書く",
  image: null,            // ステージ用の画像パス（任意。使わないなら null）
  hint: "ヒント文をここに書く",
}
```

### 対応している出題形式（`type`）

現在4種類の `type` に対応しています（`order` はさらに2つの書き方があります）。

#### `"quiz"`（選択肢から1つ選ぶ）

```js
{
  id: "stage-04",
  title: "だい4もん",
  type: "quiz",
  prompt: "日本でいちばん高い山は？",
  image: null,
  choices: ["富士山", "エベレスト", "つくば山", "阿蘇山"],
  answerIndex: 0,   // choices配列の何番目が正解か（0始まり）
  hint: "静岡県と山梨県にまたがる山だよ。",
}
```

#### `"code-input"`（キーボードで答えを入力する）

```js
{
  id: "stage-05",
  title: "だい5もん",
  type: "code-input",
  prompt: "1年で一番はじめの月は？ 数字で答えてね。",
  image: null,
  answer: "1",
  placeholder: "すうじで にゅうりょく",
  hint: "1月、2月、3月…の「1」だよ。",
}
```

入力判定は全角/半角・大文字/小文字・前後の空白を自動で吸収するので、
子どもが多少表記ゆれのある入力をしても正解と判定されやすくなっています。

#### `"order"`（並べ替え。2つの書き方がある）

**① シンプル版** - 表示されたピースを正しい順番でタップする

```js
{
  id: "stage-06",
  title: "だい6もん",
  type: "order",
  prompt: "小さい順にタップしよう。",
  image: null,
  items: ["5", "1", "3"],       // 表示される順番
  correctOrder: [1, 2, 0],       // items のインデックスで正解の順番を指定
  hint: "いちばん小さい数字から選んでね。",
}
```

上の例では `items[1]="1"` → `items[2]="3"` → `items[0]="5"` の順にタップすると正解、という意味です。

**② リッチ版** - `{label, detail}` のカードをリストの▲▼ボタンで並べ替える

```js
{
  id: "stage-07",
  title: "だい7もん：手順をならべよう",
  type: "order",
  prompt: "作業の手順を正しい順番にならべよう。カードをタップすると詳しい説明が見られるよ。",
  image: null,
  // items は「正解の順番」で書けばOK（correctOrderは省略可）。
  // 画面には自動でシャッフルされた状態で表示され、▲▼ボタンで並べ替える。
  items: [
    { label: "① まずやること",   detail: "タップすると出る詳しい説明文" },
    { label: "② つぎにやること", detail: "……" },
    { label: "③ さいごにやること", detail: "……" },
  ],
  hint: "①から順番に考えてみよう。",
}
```

`items` の各要素が `{label, detail}` のオブジェクトかどうかで、main.js側が自動的に
シンプル版／リッチ版を判定します（`type`は同じ`"order"`のままでOK）。
リッチ版では `correctOrder` を省略すると、`items`を書いた順番がそのまま正解になります。
不正解のときは「❌ ここが ちがうかも…」というヒントを出し、並べた状態のまま再挑戦できます。

#### `"blackjack"`（コンピュータと数字ブラックジャック対戦）

```js
{
  id: "stage-blackjack",
  title: "コンピュータとブラックジャック勝負！",
  type: "blackjack",
  prompt: "1〜10のすうじカードだけをつかったかんたんブラックジャック！",
  image: null,
  rules: {
    maxTotal: 21,        // これを超えたらバースト（省略時21）
    dealerStandsAt: 17,  // コンピュータがこの数値以上で引くのをやめる（省略時17）
    cardMin: 1,          // 引くカードの最小値（省略時1）
    cardMax: 10,         // 引くカードの最大値（省略時10）
  },
  hint: "17以上でステイするのが基本の作戦だよ。",
}
```

`choices` や `items` などは不要です。カードの配布・「ひく」「ステイ」・コンピュータの
自動プレイ・勝敗判定・結果表示（勝ちなら「つぎへ」、負け／引き分けなら「もういちど」で
やり直し）はすべて `main.js` の `renderBlackjack` が自動で行います。`rules` を書き換えると
バーストするラインやカードの数字の範囲を調整できます。

### 新しい出題形式（typeを増やす）を追加したい場合

1. `stages.js` に新しい `type` の名前をつけてステージを追加する
2. `main.js` の `RENDERERS` オブジェクトに `"新しいtype名": 描画関数` を1行追加する
3. 描画関数を1つ実装する（`renderQuiz` / `renderCodeInput` / `renderOrder` /
   `renderBlackjack` が実装例です）
   - 描画関数は `(stage, container, handleResult, advanceStage)` を受け取ります
   - 画面のUIを `container` に追加し、答えが決まったタイミングで
     `handleResult(true, options)`（正解）または `handleResult(false, options)`（不正解）
     を呼ぶだけでOKです（`options`は省略可。`{ wrongMessage: "..." }` のように渡すと
     共通フィードバック欄の文言を上書きできます）
   - 正解時の演出・次のステージへの遷移などは `main.js` 側が自動で行います
   - ブラックジャックのように「結果画面に自前のボタンを出して、押されたタイミングで
     次のステージに進みたい」場合は、共通フィードバックを経由せずに
     `advanceStage()` を直接呼んでもOKです

## 2. 最終画面の写真を差し替える方法

最終画面（クリア画面）で表示される写真は、以下のどちらかのファイルを置くだけで反映されます。

```
escape-game/assets/final-photo.jpg
escape-game/assets/final-photo.png
```

- 既存のファイルを、表示したい写真で **上書き** してください（ファイル名は変えないこと）
- `.jpg` と `.png` の両方がある場合は `.jpg` が優先して読み込まれます
- どちらのファイルも見つからない場合は、画面に
  「写真が見つかりません。assets/final-photo.jpg（または .png）に画像を置いてください」
  という開発者向けのメッセージが表示されます（アプリ自体はエラーになりません）

現在入っている画像はプレースホルダー（仮の色つき画像）です。本番用の写真に差し替えてください。

## 3. ローカルでの動かし方

### 方法A: ファイルを直接ダブルクリックして開く

`index.html` をダブルクリックしてブラウザで開くだけでも動作します。

### 方法B: 簡易サーバーで配信する（推奨）

```bash
npx serve .
```

または VS Code の **Live Server** 拡張機能で `index.html` を右クリックして
「Open with Live Server」を選んでも同様に動きます。

表示されたURL（例: `http://localhost:3000` や `http://127.0.0.1:5500`）に
パソコンのブラウザからアクセスして動作確認できます。

---

## 4. iPadで開く際の注意点

- iPadと配信元のパソコンを **同じWi-Fiネットワーク** に接続してください
- パソコン側で簡易サーバーを起動したら、パソコンのローカルIPアドレス
  （例: `192.168.1.10`）を調べて、iPadのSafariから
  `http://192.168.1.10:3000` のようにアクセスしてください
  - Macでのローカルアドレス確認例: `ipconfig getifaddr en0`
- 学校のネットワークなどにホスティングする場合は、`escape-game` フォルダ一式を
  そのまま静的ファイルとして配信すれば動作します（サーバー側の処理は不要です）
- 本アプリは通信を必要とせず、すべてクライアントサイドで完結するため、
  一度読み込めばオフラインでも動作します

## 5. 現在のステージについて

現在、`stages.js` には以下の4ステージが入っています。

1. くだものを当てるクイズ（`type: "quiz"`）
2. ひらがなで答えを入力する問題（`type: "code-input"`）
3. コンピュータとの数字ブラックジャック対戦（`type: "blackjack"`）
4. 紙コップスピーカーの作り方を並べ替える問題（`type: "order"`、リッチ版）

1・2は動作確認用の仮ステージなので、本番の謎解き内容が決まり次第、
自由に差し替えてください。3・4はそのまま使う想定の本番ステージです。
